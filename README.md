# netbox-plugin-mirror-session

A NetBox plugin for modelling port mirror sessions (SPAN), so they can be generated by config automation
instead of being set up by hand on the switch.

## Model

**Mirror session**: one session on one device.

- Destination: a local interface, a GRE tunnel to a capture host (source and destination IP address
  objects, optional VRF), or the CPU.
- Status `planned` or `active`. Only active sessions are meant to be configured.
- **Expiry is mandatory**, at most 6 months ahead. The UI warns when it is more than 7 days ahead, and
  more strongly when a source interface runs at 10G or faster.
- An hourly system job sets expired sessions to `planned`. It never touches the devices: the session
  disappears from a device on the next config push.

**Mirror source**: an interface in a session, with direction `rx`, `tx` or `both`.

## Installation

```
pip install git+https://github.com/nrkno/netbox-plugin-mirror-session.git@<tag>
```

```python
PLUGINS = ["netbox_mirror_session"]
```

Then run `manage.py migrate`.

## Development

```
pre-commit install
./tests/run.sh                         # test suite in the official NetBox image
NETBOX_VERSION=v4.6.0 ./tests/run.sh   # against another NetBox version
./tests/makemigrations.sh              # after a model change
```
